# MQTT select сообщает неизвестное значение

Если MQTT select получает значение, которого нет в его discovery `options`,
сначала сравните discovery и свежий ответ устройства. Не меняйте физический
режим питания только ради устранения ошибки интерфейса.

Для Yandex YNDX_00538 допустимы `low`, `medium`, `high`. Запрос чтения:

```yaml
action: mqtt.publish
data:
  topic: zigbee2mqtt/FRIENDLY_NAME/get
  payload: '{"power_type":""}'
  retain: false
```

Это `/get`, а не команда изменения `/set`. Если после чтения вместо
устаревшего `full` приходит допустимое значение, достаточно обновления
состояния. Проверьте его после следующего обычного сообщения устройства.
Расширять discovery или менять конвертер следует, только если свежий ответ
по-прежнему не согласуется с описанием поддерживаемых значений.
