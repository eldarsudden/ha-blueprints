# Уведомления о протечке

`water-leak-notifications.yaml` дополняет отдельную автоматику перекрытия воды.
Он не управляет кранами: подтверждение уведомления не может отменить их команды.

Для экземпляра нужны три помощника без принудительного `initial`, чтобы они
восстанавливались после перезапуска:

- `input_boolean`: есть неподтверждённый сигнал;
- `input_text` с `max: 100`: текущий уникальный код подтверждения;
- `input_text` с `max: 200`: помещения последней протечки.

В `notification_actions` можно выбрать несколько Mobile App notify actions.
Для сообщения используйте `{{ alarm_message }}`; кнопка с заголовком
`Подтверждаю` должна передавать `{{ ack_action }}` в поле `action`.
Значение `{{ notification_tag }}` в `data.tag` заменяет предыдущее уведомление.
В `clear_actions` можно отправить `message: clear_notification` с тем же тегом.

По умолчанию отправка повторяется каждые пять минут до подтверждения с любого
телефона или выключения помощника неподтверждённого сигнала. Старый код
подтверждения не подходит для нового сигнала. После перезапуска
неподтверждённое уведомление возобновляется с сохранёнными помещениями.

Проверять шаблоны и ветвление можно локальными тестами. Не запускайте всю
автоматику перекрытия воды ради проверки уведомления.
